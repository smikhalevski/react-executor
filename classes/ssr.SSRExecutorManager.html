    hasChanges

    • hasChanges(maxRetries?: number): Promise<boolean>

      Waits until no executors are pending, and resolves with true if the state of any executor has changed since this method was called, or false otherwise. Use it to re-render the app on the server until all data is loaded.

      The returned promise is rejected if executors are still pending after maxRetries attempts. This usually means that a plugin keeps re-executing tasks during SSR.

      Parameters

      • maxRetries: number = 10

        The maximum number of times to wait for executors that become pending again. Increase it if data is loaded in many sequential steps.

      Returns Promise<boolean>
